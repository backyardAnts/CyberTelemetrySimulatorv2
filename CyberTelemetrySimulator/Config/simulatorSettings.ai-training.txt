AI-training notes for Config/simulatorSettings.json

tickMs
- Delay between telemetry ticks. Smaller values generate more events per minute, increasing dataset density.

attackChancePerTick
- Probability of starting a new attack episode on a tick in normal/balanced modes. Higher values produce more attack-labeled events.

minDurationSec / maxDurationSec
- Randomized duration range for attack episodes in normal/balanced modes. Longer durations yield longer contiguous labeled sequences.

outputPath
- JSONL file path where generated telemetry events are appended for downstream training.

balancedDatasetMode
- When true, selects attack types to meet target ratios rather than pure randomness. Useful for balanced label distributions.

trainingDatasetMode
- When true, forces deterministic training episodes (BruteForce → PortScan → DDoS → Exfiltration) with a fixed duration. Designed for clean, repeatable training batches.

trainingEpisodeDurationSec
- Length in seconds for each forced training episode when trainingDatasetMode is enabled.

businessHoursStart / businessHoursEnd
- Defines business hours used for baseline traffic scaling. Time-of-day realism is intended for production simulation, not training mode.

dayBaselineMultiplier
- Multiplies baseline metrics during business hours (more “normal” activity).

nightBaselineMultiplier
- Multiplies baseline metrics during night hours (less “normal” activity).

afterHoursAttackMultiplier
- Multiplies attack start probability outside business hours in normal/balanced modes (clamped to 1.0). Not used when trainingDatasetMode is on.

targetClassRatios
- Desired label distribution used by balancedDatasetMode. Values are normalized if they do not sum to 1.0.
  - Normal
  - BruteForce
  - PortScan
  - DDoS
  - Exfiltration

totalEventsTarget
- Optional target total event count used to compute ratio deficits in balancedDatasetMode. If unset, ratios are based on running totals.
